# ML-поправка к дипольному решению (CatBoost)

Прототип: симулятор `mag_nav` генерирует датасет, CatBoost учится исправлять
аналитическое (дипольное) решение для маяка-соленоида.

## Схема

```
точки в 1-м октанте ─► Solenoid ─► отсчёты B(t) + шум ─► МНК-демодуляция ─► a, b
                                                                        │
                       solve_position (диполь) ◄────────────────────────┘
                                │
              признаки(a, b, p_dip) ─► CatBoost ─► поправка ─► p = p_dip + r_dip · Δ
```

- **Цель:** `(p_true − p_dip) / r_dip` — безразмерная поправка по 3 осям
  (одна модель, `loss_function="MultiRMSE"`).
- **Признаки** (18, только то, что есть у приёмника): инварианты `|a|², |b|², a·b, D`,
  нормированные на `S = |a|²+|b|²`; `log10 √S`; компоненты `a, b / √S`;
  дипольная оценка `r, u, v, w, x, y, z`. Функция `features_from_ab` одна
  и для генерации, и для инференса.
- **Train и test** генерируются независимо (разные seed); валидация для early
  stopping выделяется из train.

## Установка
```
uv add numpy scipy matplotlib catboost
```

## Запуск

Нужен пакет `mag_nav` **с исправлениями** из `mag_nav_fixes.patch` (без них
дипольное решение путает x и y, и модель будет учить баг).

```bash
uv run ml_proto/make_dataset.py --out ml_proto/data/train.npz --n 60000 --sigma 1e-9 --seed 11
```

```bash
uv run ml_proto/make_dataset.py --out ml_proto/data/test.npz --n 20000 --sigma 1e-9 --seed 22
```

```bash
uv run ml_proto/train_catboost.py --train ml_proto/data/train.npz --test ml_proto/data/test.npz --out ml_proto/results/sigma1nT
```

Параметры `make_dataset.py`: `--sigma` (СКО шума отсчётов, Тл; `0` — без шума),
`--source solenoid|dipole`, `--r-min/--r-max` (дальность, м), `--n`, `--seed`.

На выходе в `results/<run>/`: `model.cbm`, `report.json` (RMS, p95, RMS по
диапазонам дальности, важность признаков), `errors_vs_range.png`.

## Ограничения прототипа

- Один маяк с фиксированной геометрией и калиброванным `B0`. Для другого маяка
  модель нужно переобучать (или добавить его параметры в признаки).
- Точки равномерны по объёму октанта. При шуме модель частично учит этот
  априорный закон распределения (сжатие к типичным значениям) — на реальной
  траектории с другим распределением выигрыш может быть меньше.
- Ориентация приёмника не моделируется (рамки совпадают), как и в симуляторе.
