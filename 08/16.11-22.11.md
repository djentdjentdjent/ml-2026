# Отчёт за 16.11–22.11

**Проект:** «Распознавание окружающих звуков»  
**Команда:** 8

## 1. Цель работы за отчётный период

Завершить проект к защите: оформить архитектуру и результаты, собрать
сводные результаты экспериментов, воспроизводимо выбрать примеры правильных и
ошибочных ответов модели и подготовить презентацию.

## 2. Что было сделано

### 2.1. Воспроизводимая подготовка примеров для защиты

- Добавлен модуль `evaluation_examples.py` и команда
  `uv run summarize-evaluation`.
- Команда загружает сохранённую модель и прогоняет все 400 записей отложенного
  fold 5 через тот же модуль прогнозирования, который использует веб-приложение.
- Для каждой записи сохраняются истинный класс, три предсказания, оценки
  уверенности, правильность top-1 и позиция истинного класса в top-3.
- Полный результат записывается в `fold5_predictions.csv`.
- В отдельный `evaluation_examples.csv` автоматически выбираются три уверенных
  правильных и три уверенных ошибочных ответа с различными истинными классами.
- Добавлены три автоматических теста выбора примеров, проверки недостаточного
  количества классов и CSV-сериализации.

### 2.2. Итоговый анализ результатов

- Собрана итоговая таблица baseline и улучшенной модели.
- Зафиксированы лучшие и худшие классы по F1 и наиболее частые пары ошибок.
- Экспериментальная accuracy итогового RBF SVM составляет 0,6250, macro F1 —
  0,6037.
- Отдельно измерено фактическое пользовательское ранжирование top-3. Первый
  элемент совпал с истинным классом для 248 из 400 записей (0,6200), а истинный
  класс вошёл в top-3 для 321 записи (0,8025).
- Описана причина небольшого различия top-1: `SVC.predict()` использует итог
  голосования one-vs-one, а приложение ранжирует нормализованные one-vs-rest
  decision scores.

### 2.3. Архитектура и документация

## 3. Полученные результаты

### 3.1. Итоговое сравнение моделей

| Модель | Признаки | Accuracy | Macro F1 |
|---|---:|---:|---:|
| Наиболее частый класс | 154 | 0,0200 | 0,0008 |
| Логистическая регрессия | 154 | 0,4950 | 0,4846 |
| Случайный лес | 154 | 0,5575 | 0,5301 |
| RBF SVM | 154 | 0,5525 | 0,5410 |
| **RBF SVM, итоговая модель** | **424** | **0,6250** | **0,6037** |

Добавление log-mel и spectral-contrast признаков повысило accuracy на 7,25
процентного пункта и macro F1 на 6,27 процентного пункта относительно базового
RBF SVM.

## 4. Возникшие проблемы и принятые решения

- При сравнении итоговой accuracy и результатов пользовательского top-3 было
  найдено небольшое расхождение: 0,6250 против 0,6200. Проверка показала, что
  эксперимент и интерфейс используют разные допустимые правила выбора первого
  класса из результатов многоклассового SVM. Метрики не стали смешивать: в
  документации явно описаны оба способа и приведена отдельная top-3 accuracy.
- Ручной выбор удачных примеров мог привести к необъективной демонстрации.
  Вместо него добавлен воспроизводимый алгоритм, который сортирует результаты по
  уверенности и не повторяет один истинный класс внутри группы.
- Матрица ошибок для 50 классов содержит много подписей и плохо подходит для
  устного перечисления. В презентации сохранена полная матрица, а рядом вынесены
  три лучших результата и самая частая ошибка.
