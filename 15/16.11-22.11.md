# Отчёт по работе над проектом за 16.11 - 22.11 

## Тема проекта

Разработка алгоритмов машинного обучения для автоматической идентификации экзопланет на основе анализа фотометрических данных телескопа Kepler.

## Выполненные задачи

### 1. Подготовка среды разработки

- Установлен и настроен Python 3.13.
- Настроена среда разработки Visual Studio Code.
- Создано виртуальное окружение проекта.
- Установлены необходимые библиотеки для анализа данных, визуализации и машинного обучения: NumPy, Pandas, SciPy, Matplotlib, Seaborn, Scikit-learn, Jupyter, Pytest и Ruff.

### 2. Создание структуры проекта и настройка Git

- Создана структура каталогов проекта `kepler-transit-explorer`.
- Подготовлен файл `.gitignore` для исключения виртуального окружения, исходных данных, временных файлов и других элементов, не требующих хранения в репозитории.
- Инициализирован локальный Git-репозиторий.
- Создан частный репозиторий на GitHub.
- Выполнена первая фиксация состояния проекта и отправка файлов в удалённый репозиторий.

### 3. Получение и исследование данных Kepler

В качестве исходных данных выбран набор Kepler-labelled Time Series Data, содержащий фотометрические наблюдения звёзд, полученные телескопом Kepler.

Получены две таблицы:
- ExoTrain — обучающая выборка;
- ExoTest — тестовая выборка.

В ходе анализа установлено, что каждая запись содержит метку класса LABEL и 3197 значений фотометрического сигнала FLUX.

Размерности фактически используемых таблиц:
- обучающая выборка — 5087 объектов;
- тестовая выборка — 570 объектов.

Распределение классов:

Обучающая выборка:
- класс 1 — 5050 объектов;
- класс 2 — 37 объектов.

Тестовая выборка:
- класс 1 — 565 объектов;
- класс 2 — 5 объектов.

Класс 2 соответствует звёздам, для которых подтверждено наличие как минимум одной экзопланеты.

### 4. Проверка качества данных

Проведена проверка исходных таблиц на наличие проблем качества данных.

Результаты:
- пропущенные значения не обнаружены;
- бесконечные значения не обнаружены;
- полные дубликаты не обнаружены.

Также проверены типы данных и основные статистические характеристики фотометрических измерений.

### 5. Визуализация фотометрических сигналов

Построены графики световых кривых для представителей обоих классов.

Проведено визуальное сравнение характера изменения фотометрического потока во времени. Обнаружены различия в форме и изменчивости сигналов отдельных объектов.

### 6. Статистический анализ фотометрических данных

Для каждой световой кривой рассчитаны дополнительные статистические характеристики, включая среднее значение, стандартное отклонение, медиану, минимальное и максимальное значения, квантили и межквартильный размах.

Проведено сравнение статистических характеристик двух классов.

Установлено, что медианное значение стандартного отклонения фотометрического сигнала для класса 2 составляет 155,66, тогда как для класса 1 — 39,79.

Медианный межквартильный размах составляет 122,13 для класса 2 и 36,35 для класса 1.

Таким образом, в исследуемой выборке наблюдается различие в типичной изменчивости фотометрических сигналов двух классов. При этом распределения содержат экстремальные значения, существенно влияющие на средние показатели.
