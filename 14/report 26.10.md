### 2.2. Разработка генератора синтетических путевых листов

**Выполнено:**
- Создан скрипт `ml/scripts/generate_synthetic_waybills.py` (~320 строк кода).
- Архитектура генератора:

```
generate_synthetic_waybills.py
── WaybillTemplate          # Класс шаблона (форма № 3)
│   ├── draw_header()        # Шапка: номер, дата, организация
│   ├── draw_vehicle_block() # Блок ТС: марка, гос. номер
│   ├── draw_driver_block()  # Блок водителя: ФИО, удостоверение
│   ── draw_table_grid()    # Табличная сетка (линии)
├── DataGenerator            # Генератор данных через Faker
│   ├── random_doc_number()  # "№ 147", "№ АБ-2026/001"
│   ├── random_date()        # "07.10.2026"
│   ├── random_vehicle_plate()  # "А123БВ 77", "В456ГД 199"
│   └── random_driver_name()    # "Иванов И.И.", "Петров П.П."
└── BBoxTracker            # Автоматический сбор координат
    └── export_yolo()        # Запись в формате YOLOv8
```

**Ключевые технические решения:**

1. **Шаблон путевого листа** реализован на базе `Pillow` (PIL) с использованием стандартных шрифтов (`DejaVu Sans`, `Arial`) для имитации печатного и рукописного заполнения.

2. **Рандомизация данных** через библиотеку `Faker` с русской локалью (`ru_RU`):
   - ФИО генерируются в формате «Фамилия И.О.» (как в реальных путевых листах).
   - Гос. номера генерируются по паттерну `^[А-Я]\d{3}[А-Я]{2}\s?\d{2,3}$` с фильтрацией недопустимых букв (Ё, З, Й, О, Ч, Ь, Ы, Ъ).
   - Даты — в диапазоне 01.01.2020 – 31.12.2026.

3. **Автоматический сбор bounding boxes**: при отрисовке каждого текстового поля генератор запоминает координаты ограничивающего прямоугольника и сохраняет их в формате YOLOv8:
   ```
   class_id cx cy w h
   ```
   где `class_id`: 0 — `doc_number`, 1 — `doc_date`, 2 — `vehicle_plate`, 3 — `driver_name`.

4. **Вариативность шаблонов**: реализовано 3 варианта расположения блоков (для легковых, грузовых авто и автобусов), что повышает разнообразие датасета.

5. **Шум и артефакты**: добавлены опциональные эффекты — лёгкий поворот (±2°), gaussian blur, случайные «помарки» — для имитации реальных сканов.

**Запуск генератора:**
```bash
cd ml
docker compose exec ml python scripts/generate_synthetic_waybills.py \
    --num-samples 400 \
    --output-dir data/synthetic \
    --seed 42
```

## 3. Проблемы и решения

| Проблема | Решение |
|---|---|
| Faker генерирует ФИО в формате «Иванов Иван Иванович», а в путевых листах обычно «Иванов И.И.» | Написана кастомная функция `format_driver_name()`, сокращающая имя и отчество до инициалов |
| Некоторые сгенерированные гос. номера содержали недопустимые буквы (Ё, З, Й) | Добавлен фильтр `ALLOWED_PLATE_LETTERS = "АВЕКМНОРСТУХ"` |
| При малом количестве реальных данных (3 шт.) модель может переобучиться на синтетике | Реальные путевые листы вынесены исключительно в test-сет для честной оценки обобщающей способности |
| Pillow не поддерживает кириллицу «из коробки» в некоторых шрифтах | Подключён шрифт `DejaVuSans.ttf` (включён в Docker-образ), проверена корректная отрисовка всех русских букв |
