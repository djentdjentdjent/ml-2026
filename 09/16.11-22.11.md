# Отчет за десятую неделю разработки детектора пилообразных колебаний на основе МО

На предыдущем этапе детектор был дополнен вторым уровнем, который уточняет вероятность кандидата с учетом его положения в последовательности событий. Это позволило лучше учитывать временную структуру пилообразных колебаний и уменьшить число изолированных ложных срабатываний. Однако при проверке на новых и ранее отобранных сложных разрядах обнаружился обратный случай: отдельные реальные срывы могли получать низкую итоговую вероятность, даже если их локальная форма на опорном SXR-сигнале оставалась характерной. На десятой неделе работа была направлена на снижение числа таких пропусков. Для кандидатов с низкой вероятностью основной модели добавлен дополнительный fallback на компактную базовую карту признаков. Он используется как вспомогательная проверка и не заменяет основной многоканальный классификатор.

## Цели десятой недели

- Проанализировать кандидаты, которые получают низкую вероятность после основного этапа классификации
- Определить случаи, в которых низкая вероятность связана не с отсутствием срыва, а с недостаточной поддержкой дополнительными каналами или временным контекстом
- Добавить повторную проверку таких кандидатов по базовой карте признаков
- Проверить, что fallback восстанавливает часть слабых событий и не изменяет уже уверенные решения основной модели
- Выполнить контрольный просмотр результатов на новых и сложных разрядах

## Причина добавления fallback

Основная модель использует многоканальные признаки и временное окружение кандидата. Такой подход полезен для отбрасывания помех, но его решение зависит от качества сразу нескольких источников информации. В отдельных разрядах дополнительные диагностические каналы могут быть недоступны, иметь слабое отношение сигнал/шум или хуже отражать конкретный срыв. Кроме того, реальное событие может оказаться изолированным либо нарушать локальную периодичность последовательности.
В этих ситуациях кандидат может получить низкую итоговую вероятность, несмотря на заметное падение интенсивности на опорном SXR-сигнале. Простое снижение общего порога основной модели нежелательно: вместе с восстановлением пропущенных событий оно увеличило бы число ложных срабатываний на всех разрядах. Поэтому было выбрано локальное решение — отдельно перепроверять только кандидаты из области низкой уверенности.

## Использование базовой карты признаков

Для повторной проверки используется базовая карта `reference_sxr`. Она содержит 50 признаков и в первую очередь описывает локальную форму кандидата на автоматически выбранном опорном SXR-канале, а также использует компактный набор признаков D-alpha. В отличие от расширенных профилей, эта карта меньше зависит от полноты набора дополнительных диагностик и сосредоточена на непосредственной форме срыва.
Fallback включается только после получения низкой вероятности от основной модели. Кандидат не принимается автоматически: для него рассчитывается дополнительная оценка по базовой карте, после чего он возвращается в итоговый набор только при достаточном подтверждении. Если обе модели оценивают событие как маловероятное, кандидат окончательно отклоняется.
Общая последовательность принятия решения имеет следующий вид:

| Результат основной модели | Результат fallback | Итоговое решение |
|---|---|---|
| Высокая вероятность | Не запускается | Кандидат передается на постобработку |
| Низкая вероятность | Срыв подтвержден | Кандидат восстанавливается и передается на постобработку |
| Низкая вероятность | Срыв не подтвержден | Кандидат отклоняется |

Такой вариант сохраняет основную архитектуру детектора. Генерация кандидатов, многоканальная модель, анализ последовательности и объединение близких ответов продолжают работать в прежнем порядке. Новый этап является ограниченной страховочной веткой только для неуверенных решений.

## Проверка на разрядах

Обновленный детектор был проверен на новых разрядах и на сложных примерах, использованных при предыдущем анализе. Результаты основной модели сравнивались с результатами после включения fallback. Особое внимание уделялось областям, где на опорном SXR-сигнале визуально наблюдался срыв, но многоканальная или последовательностная модель давала недостаточную вероятность.
Контрольный просмотр показал несколько характерных типов решений:

| Тип кандидата | Поведение основной модели | Действие fallback |
|---|---|---|
| Слабый срыв с характерной локальной формой | Вероятность недостаточна | Событие может быть восстановлено по базовым признакам |
| Срыв при неполном или шумном наборе дополнительных каналов | Недостаточная многоканальная поддержка | Решение уточняется по опорному SXR |
| Изолированный реальный срыв | Слабая поддержка временной последовательностью | Локальная форма позволяет сохранить событие |
| Случайный выброс или шум | Низкая вероятность | Повторная проверка не подтверждает событие |
| Уверенно найденный срыв | Высокая вероятность | Решение не пересматривается |

Таким образом, fallback позволил точечно восстановить часть кандидатов, которые отбрасывались из-за низкой вероятности основного классификатора. При этом уверенные решения не изменялись, а низко оцененные кандидаты без характерной локальной формы оставались отклоненными. Визуально наиболее полезным новый этап оказался на разрядах с неоднородным качеством диагностик и нерегулярной последовательностью срывов.

## Оценка результатов

На текущем этапе проверка носит промежуточный характер. Для новых разрядов еще не подготовлена полная независимая экспертная разметка, поэтому по результатам визуального просмотра нельзя корректно рассчитывать окончательные precision, recall и F1. Также нельзя оценивать fallback только по числу восстановленных кандидатов: часть из них после экспертной проверки может оказаться ложной.
Для последующего количественного сравнения необходимо зафиксировать четыре группы результатов: события, найденные обеими версиями; события, восстановленные только fallback; дополнительные ложные срабатывания; события, которые остались пропущенными. После завершения разметки эти данные позволят оценить изменение полноты и проверить, не сопровождается ли ее рост неприемлемым снижением точности.

## Результаты десятой недели

На десятой неделе детектор был дополнен fallback-механизмом для кандидатов с низкой вероятностью. В качестве независимой повторной проверки используется компактная карта `reference_sxr`, ориентированная на локальную форму срыва и менее чувствительная к отсутствию или низкому качеству дополнительных диагностических каналов.
Предварительная проверка показала, что новый этап полезен для восстановления слабых и изолированных событий, которые выглядят характерно на опорном SXR-сигнале, но получают недостаточную поддержку от основной модели. При этом fallback применяется только к неуверенным случаям и не вмешивается в уже принятые уверенные решения.
