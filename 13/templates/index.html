About the Project

This web application predicts the average monthly temperature for selected cities in Afghanistan using a machine learning model.

The model was trained on ERA5-Land historical climate data covering the period from 2010 to 2025.

Users select a city, year, and month. The application then uses the trained Gradient Boosting model to estimate the average monthly temperature.

The application also displays historical temperature data for the selected city and month.
